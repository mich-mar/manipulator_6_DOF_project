Opis szczegółowy

Klasa implementująca bezpieczną wątkowo kolejkę danych z czujników.

Klasa DataQueue zapewnia thread-safe mechanizm przechowywania i dostępu do danych z czujników. Implementuje mechanizm kolejki o ograniczonym rozmiarze z automatycznym usuwaniem najstarszych elementów.
