Detailed Description

Klasa głównego okna aplikacji.

Implementuje interfejs użytkownika oraz logikę wizualizacji danych z czujników manipulatora. Obsługuje wykresy IMU, kątów oraz komunikację szeregową.

Konfiguruje wykresy kątów.

Konfiguracja wykresów IMU.

Konfiguruje wykresy IMU.

Tworzy i konfiguruje wykresy dla wszystkich osi (X, Y, Z) IMU. Dla każdej osi tworzone są cztery serie danych:

  • Akcelerometr
  • Żyroskop
  • Magnetometr
  • Fuzja danych
